## P1 — Shared Studio core (in progress)

Slice 1 (commit `a26cef4`, branch `v3`): the pure registry
(`FORMATS`, `getFormat`, `SAMPLES`, `SERIES_PACKS`, `DEFAULTS`,
`SERIES_CONTENT`, `clamp`, `uid`, `NEW_SLIDE`) was extracted **verbatim** from
`studio.js` into `packages/studio-core/src/registry.ts`, bundled by esbuild as
`packages/studio-core/dist/studio-core.js` (IIFE global `RGStudioCore`,
committed; CI diffs it for determinism). `studio.js`, `index.html`, the
standalone builder and all VM test loaders consume the bundle.

**Output-neutrality evidence (executed):** render smoke `[40, 16, 14336]`;
series smoke 12 packs / 0 failures; 26 unit assertions pass; 10/10 real-browser
tests pass; standalone rebuilt; P0 evidence screenshots remain byte-identical.

Slice 2 (commit `f9b8a07`): **content-brief-to-studio builder** in
`packages/studio-core/src/project-builder.ts`.

- `validateContentBrief()` — strict ContentBrief v1 validation (coded errors,
  no repair of invalid input): kinds, limits, claims with required evidence,
  http(s)-only URLs, confidence ∈ {verified, uncertain, unsupported}.
- `buildStudioProject()` — validated brief → editable v2 `.rgstudio.json`.
  Single card (`options.templateId` > `suggestedStudioTemplate` >
  `announcement`) or a coordinated series pack mirroring the editor's
  `applySeriesPack()` (theme/pattern/series/variant/chapter).
- Only brief-truthful text is overlaid (title/subtitle/tag/source/date);
  bullets are copied verbatim from `verified` claims only, and only onto plain
  line-list layouts. The normalized brief is embedded for provenance.

**Evidence (executed):** 19 unit tests written RED→GREEN plus a mutation check
(sabotaging the verified-claims filter failed exactly the bullets test, then
reverted); 2 VM integration tests restore builder output through the real
`restoreFrom()`; 1 real-browser test imports both modes through the file
input; full `npm run verify` green (47 unit assertions, 11/11 Playwright,
standalone artifact byte-identical).

Remaining P1 checklist: golden-image tolerance snapshots (next, per blueprint
8.1 step 1 — before touching renderer code); Canvas `frame` extraction;
explicit schema modules + v1→v2 migration functions; browser coverage for
undo/redo, large text and custom-dimension exports.

Slice 3 (commit `8c2d3bd`): **deterministic golden-image snapshots**.

- 7 frozen fixtures (`tests/fixtures/golden/`) rendered through the real
  editor and pixel-compared against committed baselines
  (`docs/evidence/golden/<fixture>.<engine>.png` + `manifest.json`).
- Engine-specific baselines: chromium + firefox (WebKit cannot start on this
  host — see environment note below); `npm run update:goldens` regenerates.
- Readable failure diagnostics: changed-pixel count/ratio, max/mean channel
  delta, changed-pixel bounding box, live-canvas attachment on failure.
- Calibration evidence: chromium noise exactly 0 across runs; firefox has a
  second stable glyph-AA state (~1,000 px = 0.07%, delta 68 → bound 96);
  a deliberate one-word mutation measured 1.6% / delta 224 and was caught on
  both engines (then reverted).

**WebKit environment blocker:** `npx playwright install firefox webkit`
downloads both, but WebKit refuses to start (missing system libraries,
`--with-deps` needs sudo which this host does not grant). Chromium+Firefox
run locally; CI installs chromium+firefox with dependencies. WebKit coverage
becomes possible on CI or a host with install rights — tracked as an external
environment limitation, not a code gap.

## Evidence environment (P0)

  v24.21.0, npm 11.19.0.
- Playwright Chromium headless shell `156.0.8078.4` (playwright build v1248)

  design cost. Test bodies are fast; CI runs on Linux runners without it.
